# ARCANA Encyclopedia

Mobile-first prototype for GitHub Pages.

## Publish
1. Create a GitHub repository (example: `arcana-encyclopedia`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.

`design-reference.png` is the visual concept reference and is not required by the website.
